**Velvet Shadow** — a top-down stealth heist in three galleries, drawn entirely in
canvas 2D. You are Wren, a burglar in the Marlowe Gallery after closing time: sneak
past patrolling guards whose vision cones sweep and rotate, hide behind crates and
walls that really do block their sight, pocket the relics, and reach the green EXIT
unseen. A guard's suspicion fills while you stand inside its cone and drains when
you slip away — a near miss is recoverable, a full meter means you are caught.
Throw a pebble with a click to pull a guard off its patrol and open a gap; hold
Shift to sneak slower and quieter. Each gallery adds guards, speed and range: the
Foyer (2 guards), the Vault Hall (3), the Rooftop Garden (4). Guard footsteps fade
with distance, so you hear a patrol coming before you see it.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```

Any static file server pointed at `game/` works just as well — the game is plain HTML and
ES modules with no build step and no network calls. Hand the entry in with
`mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
